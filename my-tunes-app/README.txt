My Tunes - Android app project

1. Put every file in this folder into a GitHub repository (see the steps in chat).
2. GitHub builds the app: Actions tab > Build Android APK > Run workflow.
3. Download My-Tunes-APK from the finished run, unzip it, and install My-Tunes.apk on a phone.

To change the app later, edit www/index.html and upload it again.
